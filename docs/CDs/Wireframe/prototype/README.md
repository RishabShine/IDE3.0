# IDE3.0 Wireframe Prototype

A clickable mock-up of the IDE3.0 panels for the Wireframe Report (CD-Fall).
All data shown is an invented example.

## Open it

**In your browser (no download):**
<https://raw.githack.com/RishabShine/IDE3.0/main/docs/CDs/Wireframe/prototype/index.html>

**Or locally:** download [`index.html`](index.html) (Raw, then save) and
double-click it. It is a single file with no dependencies and works offline.

## Use it

Click the steps in the left sidebar to move between the six screens. The
buttons work: answer the clarifying question, add or decline stakeholders,
approve, edit, or reject user stories, and release the approval gate once every
story is decided.

Screenshots of every screen are in the
[Wireframe Report](../WireframeReport.tex).
