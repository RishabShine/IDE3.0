# Design documentation (IDE3.0)

| Folder | Document |
|--------|----------|
| `SoftArchitecture/` | Module Guide (MG) |
| `SoftDetailedDes/` | Module Interface Specification (MIS) |

These documents decompose IDE3.0 into modules (host IDE surface, workflow
controller, intent capture, elicitation, verification, etc.) and specify
leaf-module interfaces. They accompany the Volere SRS and Hazard Analysis.
